# Ответы на вопросы защиты

## Основные 7 вопросов

**1. Почему AccessEvent лучше аналогов?**
Существующие платформы строятся под звуковой канал. AccessEvent — вокруг визуального: цветные уведомления, читаемые бейджи, ARIA-атрибуты. Соответствует WCAG 2.1 AA.

**2. Роли и авторизация?**
Три роли: user, organizer, admin. Пароль хешируется (werkzeug.security). JWT-токен выдаётся при входе и передаётся в заголовке Authorization: Bearer. Декораторы @token_required и @role_required проверяют подпись и роль.

**3. Нагрузка 10000 пользователей?**
Приложение stateless — можно запустить несколько контейнеров за балансировщиком. Индексы на горячих таблицах, пул соединений, кеширование списка мероприятий, асинхронная обработка уведомлений.

**4. Что такое ARIA?**
Атрибуты HTML для экранных читалок: aria-label, role, aria-live. В проекте — aria-label на навигации, aria-live на уведомлениях. Проверялось через тест-кейсы TC-11, TC-12.

**5. Сколько тестов?**
14 pytest: 6 тестов моделей (создание пользователя, дубликаты, обязательные поля) и 8 тестов API (регистрация, валидация, JWT, CRUD). Все по схеме AAA.

**6. Самый сложный баг?**
Дубликат email давал 500 вместо 400 из-за UNIQUE-констрейнта. Исправлено проверкой User.query.filter_by(email).first() перед commit. Зафиксировано в BUG-01.

**7. Что добавите в первую очередь?**
Push-уведомления и интеграцию с календарём — чтобы напоминания приходили без открытия приложения.

## Дополнительные 8 вопросов

**Flask или Django?** Flask легче, полный контроль над структурой. Django с админкой избыточен.

**Что такое ORM?** SQLAlchemy — таблицы БД как Python-классы. Плюсы: защита от SQL-инъекций, переносимость.

**Что такое JWT?** JSON Web Token, header.payload.signature. Передаётся в Authorization: Bearer.

**Почему SQLAlchemy?** Безопасность, переносимость (SQLite → PostgreSQL), читаемость.

**Что такое CI/CD?** Continuous Integration — проверка push (GitHub Actions). Continuous Delivery — сборка GHCR-образа.

**Зачем контейнеризация?** Приложение и зависимости в образе, работает одинаково везде.

**Что такое нормализация?** Устранение избыточности: 1НФ, 2НФ, 3НФ.

**Что такое WCAG 2.1 AA?** Стандарт доступности веба: контраст, клавиатура, ARIA, альтернативы звуку.
