# Тезисы выступления: AccessEvent

**[0:00–0:30] Проблема и цель**

Добрый день! Я защищаю проект AccessEvent — веб-платформу для организации мероприятий, доступную людям с нарушениями слуха. Обычные платформы используют звуковые уведомления, что делает их бесполезными для этой аудитории. Цель — платформа с визуальными уведомлениями.

**[0:30–1:30] Требования**

Ключевое требование — соответствие WCAG 2.1 AA. Главный стейкхолдер — участник с нарушением слуха.

**[1:30–3:00] Архитектура**

Трёхслойная: клиент (HTML/CSS/JS + Jinja2), сервер (Flask + JWT), данные (SQLAlchemy ORM). Модели: User, Event, Registration.

**[3:00–5:00] Демонстрация**

Регистрация организатора → создание инклюзивного мероприятия → регистрация участника → запись на мероприятие. Всё без звука.

**[5:00–6:00] Тестирование**

14 тестов pytest. GitHub Actions проверяет код автоматически.

**[6:00–7:00] Оценка**

SWOT: сильные стороны — инклюзивность и CI/CD. Развитие: push-уведомления, календарь, субтитры.
